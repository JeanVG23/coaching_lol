## Ce que Perplexity peut faire sur tes repos

### 👁️ Lecture
- Lire le contenu de n'importe quel fichier dans le repo
- Parcourir l'arborescence des dossiers et fichiers
- Consulter l'historique des commits
- Voir les branches existantes
- Lire les issues et pull requests ouvertes
- Accéder aux releases et aux tags

### ✏️ Écriture & Modifications
- **Créer** de nouveaux fichiers (comme ce README !)
- **Modifier** des fichiers existants (avec commit automatique)
- **Supprimer** des fichiers
- Pousser plusieurs fichiers en un seul commit (`push_files`)

### 🌿 Gestion des branches
- Créer de nouvelles branches
- Lister toutes les branches du repo

### 🐛 Issues & Pull Requests
- Créer, lire et mettre à jour des issues
- Ouvrir des pull requests
- Lire les commentaires et reviews de PRs
- Soumettre des reviews de code

### 🔍 Recherche
- Rechercher du code dans tous tes repos
- Chercher des commits par message ou auteur
- Rechercher des repos GitHub par nom ou description

## ⚠️ Sécurité

Toute action d'écriture (création, modification, suppression) est soumise à ta **confirmation explicite**. Perplexity ne modifie jamais du code sans que tu le demandes clairement.
